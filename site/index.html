How it was done

  1. Find the protocol. Decompiled the Wearfit Pro app and cross-checked it against Gadgetbridge's WearFit driver: a Nordic UART service carrying AB LEN FF CMD KIND ARGS frames.
  2. Prove it on a laptop. A Python/bleak client read battery and firmware, set the clock, made the watch vibrate and streamed live heart rate.
  3. Hit a wall. Connections started stalling: Linux's Bluetooth stack always opens with an MTU exchange, and this watch never answers it.
  4. Diagnose it. btmon captures showed the link hanging on that one request.
  5. Work around it. Talking raw ATT on channel 4 skips the MTU exchange entirely. Android only sends it when asked, so the phone app simply never asks.
  6. Log it. The phone app syncs readings every 6 hours as a pull request. A check validates them, then this page rebuilds.
